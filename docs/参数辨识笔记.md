# 第 0 章 方法论

## 0.1 三类参数，三种标记

| 标记 | 含义 | 例子 |
|---|---|---|
| **✓实测** | 板上数据直接反推，有原始记录 | R = 3.5 Ω、摩擦电流 0.033 A |
| **≈反推** | 由实测数据经模型折算，依赖其他参数 | ψf = 0.0034 Wb、J ≈ 3.2e-6 |
| **○设计** | 人为选取、来自规格书，或**由架构算出的常数** | 电流环带宽 400 Hz、α = 0.06、**Δt = 150 µs** |
| **?待测** | 还不知道 | 采样链绝对增益 k、粘滞摩擦 b、齿槽转矩幅值 |

## 0.2 六行记录模板

```
已知  ：本次计算用到的输入量（含数值与来源：✓/≈/○）
条件  ：测量时的工况声明（轴状态、模式、给定、是否饱和、是否稳态）
实测  ：从哪个通道读到什么数（原始数据，带单位）
公式  ：本次用的理论公式（只含"已知"和"实测"里出现过的符号）
计算  ：把数代进去的过程
得到  ：结果 + 置信度 + 主要误差源
```

三条写作纪律：公式里的每个符号都要在"已知/实测"里出现过；"条件"必须写清**让哪些项消失了**；数据必须带**通道号和单位**（同一个 ch15 在斜坡段 = 摩擦+加速，稳态段 = 摩擦）。

> 纯推导/纯设计的块（增益设计、限幅定界、自举论证）没有"实测"行，那是刻意的。

## 0.3 辨识三纪律

**纪律一：先数未知数 —— 方程数 ≥ 未知数。**
踩过的坑：用 `u_d ≈ −ωe·ψf·sin δ` 反推 ψf，而 δ 又用同一组 `u_d` 数据标定 —— 一个方程两个未知数，**循环论证**。数据"自洽"不能证明结果正确：取 δ = 14.8° 得 ψf = 0.0033、取 δ = 11.8° 得 0.0041，两个都自洽。

| 辨识对象 | 未知数 | 可用方程 | 结论 |
|---|---|---|---|
| R（夹死轴） | R | `u_q = R·i_q` | 1:1 ✓ |
| ψf + δ（顶速 d 轴） | **2** | `u_d = −ωe·ψf·sin δ` | ✗ 必须先固定一个 |
| ψf（顶速幅值） | ψf | `\|u\|² = (ωe Lq iq)² + (R iq + ωe ψf)²` | ✓ 方程里没有 δ |
| J（匀速加速） | J | `J·α = Kt·i_q − T_fric` | 含摩擦 ⇒ 用两点法消掉 |

**纪律二：假设必须显式写出来，并给灵敏度与验证手段。**
踩过的坑：幅值法隐含假设 `i_d = 0`。实际只需 i_d **已知**；"假装为 0"的误差 ≈ **0.41 %/0.01 A**（= Ld·i_d/ψf）。角度错位还会造出"假 i_d" ≈ i_q·sin δ ⇒ 所以要在**顶速空载点**（i_q 小）测。

**纪律三：能差分就差分。**

| 想消掉 | 手段 | 公式 |
|---|---|---|
| 管压降/死区 | 两个电流点的稳态电压 | `R = (u2−u1)(Udc/2)/(i2−i1)` |
| 库仑摩擦 | 两组固定电流的加速度 | `J = Kt·(I2−I1)/(α2−α1)` |
| 零位误差 vs 延迟 | 两个转速点扫描（两者对 ωe 的依赖不同） | 见 2.6 |

## 0.4 参数依赖图

```
E1 bias、k ┐
E2 offset、dir ┘→ 一切电流/角度测量的前提
   ├─→ R = 3.5 Ω（夹死轴稳态）
   │      └─→ L（τ = L/R，电压阶跃）
   ├─→ ψf = 0.0034 Wb（顶速幅值法，需 R、Lq、Udc、ωe、i_d/i_q）
   │      ├─→ Kt = 1.5·pp·ψf ──→ J ≈ 3e-6 ──→ 速度环 kp/ki
   │      └─→ 顶速上限预测
   └─→ Δt = 150 µs（**架构常数** T_mid + T_pwm，可直接算；不依赖 ψf）
```

| 参数 | 直接依赖 | 依赖 δ？ | 依赖 ψf？ |
|---|---|---|---|
| R | Udc、采样链 | 否 | 否 |
| L | R、时间轴 | 否 | 否 |
| Δt | 只依赖 "min\|Ud\|" 判据 | — | **否** |
| ψf（幅值法） | R、Lq、Udc、ωe、i_d/i_q | **否** | — |
| ψf（d 轴法） | δ | **是** | — |
| Kt / J / 速度环增益 | ψf → Kt → J | 否 | 是 |

## 0.5 可辨识工况对照表

| 工况 | 消掉了什么 | 因此可测 |
|---|---|---|
| 夹死轴（ωe = 0） | 反电动势与交叉耦合项 | R |
| 自由轴顶速（稳态、电压饱和） | 加速度项 | ψf、Δt |
| 自由轴匀速加速（α 恒定） | 稳态项 | J |
| 两点锁轴（两个已知电角度） | 未知 offset | dir |
| 断电外部拖动（i = 0） | 电流全部项 | ψf（反电动势法，最干净） |

## 1.2 单位与符号（先钉死）

| 量 | 符号 | 工程内宏/字段 | 关键换算 |
|---|---|---|---|
| 母线电压 | Udc | `MOTOR_UDC_NOMINAL` | 相电压峰值 = **u·(Udc/2)** |
| 相电阻 / dq 电感 | R / Ld,Lq | `MOTOR_R_PHASE` / `MOTOR_LD,LQ` | 表贴式 Ld ≈ Lq |
| 永磁磁链 | ψf | `MOTOR_FLUX` | Kv ≈ 400 rpm/V |
| 极对数 | pp | `MOTOR_POLE_PAIRS` = 7 | 12 槽 14 极 |
| 转矩常数 | Kt | 派生 | **Kt = 1.5·pp·ψf** |
| 电流 | i | `state.id/iq`（ch7/ch8） | 采样码 → (raw−bias)×1.611 mA |
| 电压（控制器量） | ud/uq | `state.ud/uq`（ch9/ch10） | **是调制比，不是 V！** 1.0 ↔ Udc/2 |
| 机械/电角速度 | ωm / ωe | — | **ωe = pp·ωm**；rpm→rad/s ×2π/60 |
| 机械/电角度 | θm / θe | ch0/ch1 | **θe = dir·pp·θm + offset** |

> 最容易错：**ud/uq 是调制比**。看到 "Ud = −0.239" 要立刻换算成 −0.239×6 = −1.43 V。

## 1.3 数学模型与三个特例

```
u_d = R·i_d − ωe·L_q·i_q
u_q = R·i_q + ωe·(L_d·i_d + ψf)
|u|² = (R·i_d − ωe·Lq·i_q)² + (R·i_q + ωe·Ld·i_d + ωe·ψf)²       ← 幅值形式（坐标系无关）
T_e = 1.5·pp·ψf·i_q = Kt·i_q
J·dωm/dt = T_e − T_fric − B·ωm
```

| 特例 | 条件 | 化简 | 用途 |
|---|---|---|---|
| 夹死轴 | ωe = 0 | `u_q = R·i_q` | 测 R |
| 自由轴稳态 | dω/dt = 0、i_d = 0 | `u_q = R·i_q + ωe·ψf` | 测 ψf |
| 自由轴匀速加速 | i_d = 0、α 恒定 | `J·α = Kt·i_q − T_fric` | 测 J |

## 1.4 测试环境

**上电流程**：电流偏置校准 → 编码器两点锁轴校准 → 停止（或按 `TEST_MODE` 进测试模式）

```
CAL:   off=… dir=… dmech=… expect=… ok|SUSPECT    校准结果（一次性）
CFG1/CFG2: 本次生效参数（一次性）
FAULT: OC trip / DRV8311 nFAULT                    故障（一次性）
CSV:   16 通道周期数据（PRINT_PERIOD_MS=20 → 50 Hz）
```

| ch | 0 | 1 | 2 | 3 | 4~6 | 7/8 | 9/10 | 11~13 | 14 | 15 |
|---|---|---|---|---|---|---|---|---|---|---|
| 内容 | 机械角<br>(rad) | 电角度<br>(rad) | 转速<br>(rpm) | 位置<br>(rad) | Ia/Ib/Ic<br>(A) | Id/Iq<br>(A) | Ud/Uq<br>(调制比) | Du/Dv/Dw | spd_ref<br>(rpm) | **iq_ref**<br>(A) |

> 常盯：**ch2**（转速）、**ch15**（送进电流环的 q 给定）、ch8（Iq 反馈）、ch9（Ud：看角度是否偏）、ch7（Id：对齐与采点有效性）。

**限幅体系（三层）**

| 层 | 值 | 位置 | 说明 |
|---|---|---|---|
| 用户限幅 | 0.5 A（额定） | `mc.target.iq_max` | 速度/位置模式的转矩限幅 |
| 保底限幅 | 0.9 A | `CURRENT_I_MAX_GUARD`（常量） | 运行中不可改；实际生效 = min(用户, 保底) |
| 过流保护 | 1.2 A / 连续 3 拍 | 软件 latch | 事后兜底 |

```
已知  ：Udc/2 = 6 V、R = 3.5 Ω（E5）、u_max = 1.10（E7）
条件  ：满调制、堵转
公式  ：I_stall = u_max·(Udc/2)/R
计算  ：1.10 × 6 / 3.5 = 1.886 A（14 V 下 2.20 A）
得到  ：过流阈值必须 < 1.886 A 且 ≫ 0.5 A ⇒ 取 1.2 A（2.4× 额定、堵转的 64%）
```

# 第 2 章 调试主线：从全开环到速度环

```
E1 电流偏置校准   → 采样零点 + 增益 k
E2 编码器两点锁轴 → offset + dir（角度对齐）
E3 全开环 VVVF    → 功率级、相序、编码器跟随（零依赖起点）
E4 半开环         → 角度对齐是否正确（Id ≈ 0）
E5 电流环(夹死轴) → 增益设计 + 测 R
E6 电流环(顶速)   → 测 ψf（幅值法）+ 算 Δt（架构常数），一次实验同时得到
E7 顶速调试史     → 四处改动把 1947 → 2578 rpm
E8 速度环         → 测 J、定带宽
```

> 每节的"依赖/假设/灵敏度/验证"汇总在 **附录 B**；本节写流程、判据与六行块。

## 2.1 E1 电流偏置校准（MODE_CURRENT_CALIB）

**一句话**：求出三相电流的零点码 `bias[3]` 和换算系数 k，否则后面所有电流都是错的。

```
已知  ：ADC 12bit（中点 2048）、校准拍数 N = 4096、CSA 增益/分流/VREF 为硬件给定值
条件  ：PWM 0%（三相下桥全通 ⇒ 绕组短路 ⇒ 真零电流）、驱动器使能、转子静止
实测  ：三相注入通道原始码累加 Σraw_a/b/c（4096 拍）
公式  ：bias = (Σraw + N/2) >> log2(N)      i = (raw − bias) × k
计算  ：k = CSA增益 × 分流电阻 / VREF × 4096 → 1.611 mA/LSB（量程 ±3.3 A）
得到  ：bias[3]（✓实测）、k（○ 绝对增益未独立验证，见 5. 反向标定）
```

**注意**：驱动器必须使能（DRV8311 sleep 拉低时 SOx 没有有效零点）。
**坑**：早期 bias 没采对，读数恒为量程上限 ≈3.3 A，被误读成"0.3 调制比导致 3.x A 电流"。

## 2.2 E2 编码器两点锁轴校准（MODE_ENCODER_CALIB）

**一句话**：定出 `offset`（零点）**和** `dir`（方向）—— 只做单点会漏掉方向，导致闭环变正反馈。

**模型**：`θe = dir·pp·θm + offset`；把电压矢量锁在两个已知电角度，各等稳定后平均机械角：

| 点 | 施加矢量 | 真实 θe | 方程 |
|---|---|---|---|
| 0 | Uα = U（电角度 0°） | 0 | `0 = dir·pp·θm0 + offset` |
| 1 | Uβ = U（电角度 +90°） | π/2 | `π/2 = dir·pp·θm1 + offset` |

```
已知  ：pp = 7（○规格书）
条件  ：轴自由；锁轴 u = 0.30（调制比）；每点等"位置波动 < 0.1°机械"或超时 1 s，
        再连续 1000 拍（50 ms）平均机械角
实测  ：ch0 原始机械角 θm0、θm1（rad）
公式  ：dir = sign(θm1 − θm0) ；offset = NormRad(−dir·pp·θm0)
        理论位移 θm,expected = π/(2·pp) = 0.224 rad = 12.9°
计算  ：Δθm 解绕到 (−π, π]；比值 r = |Δθm|/θm,expected；0.25 ≤ r ≤ 1.5 才认符号，
        越界 ⇒ suspect=1、dir 按 +1 兜底并打印告警
得到  ：offset（rad）、dir（±1）；零位残余偏差 3~5° 电角度（✓实测）
```

**为什么必须两点**：单点只能定零点。方向错时电角度随转子**反向**变化 ⇒ 角度闭环变成**正反馈** ⇒ 平均转矩 0 ⇒ **电机原地只抖不转、电流全落在 d 轴，加大电压也没用**。这是最初"锁轴对齐做了、半开环却不转"的根因。

**锁轴电压与校准质量**

```
已知  ：Kt = 0.0357 N·m/A（≈）、Udc/2 = 6 V、R = 3.5 Ω（E5）
条件  ：锁轴（堵转）稳态，ωe = 0
公式  ：I = u·(Udc/2)/R ；T = Kt·I
计算  ：u=0.15 → I=0.257 A → T=9.2 mN·m ；u=0.30 → I=0.514 A → T=18.4 mN·m
得到  ：u=0.15 时零位残余 6~9°；u=0.30 时 3~5° ⇒ 取 0.30（现用）
```

**残余偏差从哪来**：12 槽 14 极齿槽周期 = 360/LCM(12,14) = 4.29° 机械 = **30° 电角度**；转子每次停在"电磁对齐转矩 vs 齿槽/静摩擦"的不同平衡点 ⇒ 每次上电偏差随机。后果是有效电压 ∝ cos δ：δ=10° → 顶速 2539 rpm、δ=15° → 2490 rpm —— 这就是"有时 2600、重启后达不到"。

**这个残余在 E6/E8 里能直接看到**：延迟补偿到位后 d 轴仍残留 `Ud = −0.058`（把交叉耦合项 `ωe·Lq·i_q` 一起算进去，等效 **δ_res ≈ −1.70°**；早先写"3.1°"是漏掉了该项）；**低转速下同样存在**：1000 rpm 闭环实测 ch9 = −0.027 ⇒ δ_res = **−2.97°**（见 2.8）。两处都落在上面"每次上电随机 3~5°"的量级内，属于这里的零位残余，不是延迟问题（单点无法把两者拆开，见 9.3）。

**判据**：`CAL:` 行必须 `dir=… ok`；`SUSPECT` 表示第二点转子几乎没动（查锁轴电压、机械卡死、编码器是否更新）。
**根治方向（未做）**：慢速旋转标定（矢量匀速转 1~2 圈，对 θm 与指令角取平均，把齿槽平均掉）+ 校准结果落 Flash。**这条也是 E6 残余误差的根治手段**。

## 2.3 E3 全开环 VVVF（MODE_FULL_OPEN_LOOP）—— 零依赖起点

**一句话**：不用任何反馈和参数，先确认功率级、相序、编码器接线都是通的。

```
已知  ：无（不需要任何电机参数）
条件  ：TEST_MODE 1；开环电角度每拍积分 θ += 2π·f/20kHz；ol_volt = 0.05、ol_freq = 5 Hz
实测  ：ch2 是否转、ch1 编码器电角度、ch7/ch8 Id/Iq、ch4~6 相电流
公式  ：无（纯开环）；相电流预期 ≈ u·(Udc/2)/R（堵转时）
得到  ：系统可用性判据（下表），不产出参数
```

| 现象 | 说明 |
|---|---|
| 电机平稳慢转，电流 ≈ u·(Udc/2)/R | 功率级、相序正确 ✓ |
| ch1 与开环角**同向同速** | 编码器接线与方向正常 ✓ |
| ch7/ch8 平稳 | 校准质量初步可用 |
| Id/Iq 呈正弦波动 | offset/dir 有问题 → 回 E2 |

**注意**：SVPWM 相电压是**马鞍波**（含零序分量），线电压才是正弦；串口 50 Hz 采样，观察波形时电频率 ≤10 Hz。

## 2.4 E4 半开环（MODE_HALF_OPEN_LOOP）—— 验证角度对齐

**一句话**：角度用编码器闭环、电压开环给定，专门检验 E2 的校准结果。

```
已知  ：offset、dir（E2）
条件  ：TEST_MODE 2；ud = 0、uq = 0.04（调制比）；轴自由
实测  ：ch7 Id、ch8 Iq 的平稳性；ch2 是否稳定旋转
公式  ：对齐正确 ⇒ 矢量与转子同步 ⇒ Id ≈ 0
得到  ：校准质量判据（下表），不产出新参数
```

| 现象 | 结论 |
|---|---|
| 平稳旋转，**Id ≈ 0**，Iq 平稳 | 对齐正确 ✓ |
| 电流波动/卡顿，Id、Iq 都在动 | offset 有误 |
| **不转只抖，电流全在 d 轴** | dir 错（或校准未完成） |
| 完全不转且无电流 | 驱动未使能 / 限幅为 0 |

**注意**：转子自由时 0.04 调制比（0.24 V）就能把它带到约 100 rpm 空载转速，电流随之掉到摩擦值——看着像"没电流/堵转"，其实在转。

## 2.5 E5 电流环 + 夹死轴：增益设计 + 测 R

**一句话**：静态测试必须夹死轴；一次实验同时验证采样零点/符号/增益，并得到相电阻。

> ⚠ 轴不夹死时电机会被加速到电压顶速，电流只剩摩擦值，看着像"电流环跟踪不上"，其实环路早已饱和。

**增益怎么来的（此时 R、L 只有粗略值）**

```
已知  ：R ≈ 3.5 Ω、L ≈ 1.4 mH（○万用表/规格书）、Udc/2 = 6 V、目标带宽 400 Hz
条件  ：对象为一阶 RL（最小相位、无谐振）；采样 20 kHz（50 拍/周期）
公式  ：ωc = 2π·BW ；kp = L·ωc/(Udc/2) [调制比/A] ；ki = R·ωc/(Udc/2) [调制比/(A·s)]
        （PI 零点对准对象极点 R/L ⇒ 零极点对消）
计算  ：ωc = 2513 rad/s ；kp = 0.0014×2513/6 = 0.586 ；ki = 3.5×2513/6 = 1466
        校验 ki/kp = 2500 = R/L ✓
得到  ：kp = 0.586、ki = 1466（○设计）
```

> 逻辑：**先用粗略的 R/L 把环建起来**（低增益必然稳定），再用这个环把 R 测准，最后回代修正增益（详见第 5 章）。

**用这个环测 R**

```
已知  ：Udc = 12.0 V（万用表，未进 ADC）
条件  ：轴夹死 ⇒ ωe = 0 ⇒ u_q = R·i_q（反电动势与交叉耦合项消失）；
        电流环稳态（等 >5τ，τ = L/R = 0.4 ms）；u ≈ 0.29 远未饱和（限幅 1.10）
实测  ：测点1 ch8 Iq = 0.508 A、ch7 Id = 0.000 A、ch10 Uq = 0.292（调制比）
        测点2 ch8 Iq = 0.502 A、ch10 Uq = 0.300
公式  ：R = u_q·(Udc/2)/i_q
计算  ：0.292 × 6 / 0.508 = 3.449 Ω ；0.300 × 6 / 0.502 = 3.586 Ω
得到  ：R = 3.5 Ω（✓实测）
        误差源：① Udc 用名义值 ② 采样链绝对增益未验证 ③ 单点法含管压降/死区
        ⇒ 更准：两点斜率法 R = (u2−u1)(Udc/2)/(i2−i1)（见 3.1）
```

**这一次实验同时确认了四件事**：① `Id = 0.000` ⇒ **采样零点**正确，且电流环在自己坐标系里收敛到位（⚠ **这不能证明编码器零位角对**：环路与观测用的是同一套角度，`i_d'` 被调成 0 是必然的，任何角度误差都与它无关——角度误差只在**有转速**时以"反电动势漏进 d 轴"的形式暴露在 ch9 上，见 2.8/E8 与第 9 章）；② Iq 跟得上正给定且不跑飞 ⇒ 反馈**符号**正确（符号反 = 正反馈 ⇒ 顶到 1.89 A 堵转值 ⇒ `FAULT: OC trip`）；③ 稳态无静差无振荡 ⇒ 增益量级合适、400 Hz 带宽在 20 kHz 采样下合理；④ 稳态满足 `u_q = R·i_q` ⇒ R 可测（且与增益无关，原理见第 5 章）。

| 故障现象 | 原因 | 对策 |
|---|---|---|
| 立刻 `FAULT: OC trip` | 电流反馈符号反 | `DRV8311_I_SIGN` 改 −1 |
| Iq 顶在限幅但轴不转 | 轴被夹住（正常）；轴自由则已到顶速 | 看 ch2 |
| Id 不为 0 | 编码器零位/方向错 | 回 E2 |
| 电流读数恒定 ≈3.3 A | bias 没采对 | 回 E1 |

## 2.6 E6 顶速测试：测 ψf 与 Δt（一次实验同时得到）★

**一句话**：轴自由、电流环给 `iq* = 0.5 A`，电机升到电压极限。**同一帧数据**做两件事：电压矢量的**幅值**给出 ψf（不含 δ）；相位给出 δ，用来核对 **Δt**（Δt 是架构常数，算出来即可、不需要实验）。**上电零位误差不在本节讨论**（它归 E2，只在 ③ 里做一句归因）。

**顶速点的实际状态（后面公式都基于它）**

- 电流环想给 0.5 A，但电压不够：0.5 A 在顶速需要 |u| ≈ 1.38（> 限幅 1.10）
- 于是环路饱和，**实际电流由物理决定**：机械平衡定 iq（`Te = T_fric` ⇒ iq ≈ 摩擦电流），电压约束再定 id
- 解电压方程（|u| = 1.10、iq = 0.06 A、n = 2578 rpm）⇒ **id ≈ −0.014 A**
- ⇒ 顶速点电流极小（|i| ≈ 0.06 A），这正是幅值法在这里最准的原因
- **可验证的预测**：顶速时 ch8 ≈ 0.06 A（**不是**给定的 0.5 A）、ch7 ≈ −0.01 A；若实测明显不同，说明摩擦电流或电机参数估计有问题

**一次实验拿到的数据**

| 量 | 通道 | 点 A（现用代码） | 点 B（旧幅值近似） |
|---|---|---|---|
| 转速 | ch2 | 2578 rpm | 2343 rpm |
| Ud / Uq | ch9 / ch10 | −0.058 / 1.0996 | −0.239 / 0.980 |
| \|u\| = √(Ud²+Uq²) | 计算 | 1.1010 | 1.0088 |
| Id / Iq | ch7 / ch8 | ≈ −0.01 / ≈ 0.06 | ≈ 0 / ≈ 0.06 |

> \|u\| 用同一帧算出来，**不假设它等于限幅**（点 B 的真值 1.0088 就小于当时的"以为" 1.10）。

**① 测 ψf：幅值法（不需要 δ）**

原理：控制器角度错了 δ，只是把这个"物理上必需的电压矢量"在它**自己的 d/q 轴**上重新分解了一次 —— **矢量的幅值不变**。所以幅值方程里没有 δ：

```
已知  ：Udc/2 = 6 V、pp = 7、R = 3.5 Ω（E5 ✓）、Lq = 1.4 mH（○）、i_q ≈ 0.06 A
条件  ：轴自由、稳态、电压饱和；同一帧读 u 与 i
实测  ：点 B：n = 2343 rpm、Ud = −0.239、Uq = 0.980、|u| = 1.0088
公式  ：ψf = [ √( (|u|·Udc/2)² − (R·i_d − ωe·Lq·i_q)² ) − R·i_q − ωe·Ld·i_d ] / ωe
        （i_d = 0 时退化为 ψf = [√((|u|Udc/2)² − (ωe Lq i_q)²) − R i_q]/ωe，**都不含 δ**）
计算  ：U = 1.0088 × 6 = 6.053 V ；ωe = 1717.5 rad/s
        ωe·Lq·i_q = 0.144 V ；R·i_q = 0.21 V
        ωe·ψf = √(6.053² − 0.144²) − 0.21 = 5.841 V ⇒ ψf = 0.00340 Wb
得到  ：ψf = 0.0034 Wb（≈反推，与 δ 无关）
        点 A（2578 rpm、|u| = 1.101）⇒ 0.00338 Wb ✓ 两点一致
```

| 假设（都可现场验证） | 灵敏度 | 怎么验证 |
|---|---|---|
| 稳态 | — | 相邻两帧 \|u\|、i_q 变化 < 1 % |
| i_d ≈ 0（公式里已含 i_d 项，假装为 0 才有误差） | **0.41 %/0.01 A** | 同一帧看 ch7：`\|ch7\| ≤ 0.02 A` 才采信 |
| \|u\| 用同帧算出 | — | 与限幅值对照（点 B 就不等于 1.10） |
| 顶速点电流小（i_q ≈ 摩擦） | 假 i_d ∝ i_q ⇒ 顶速点 ≤0.6 % | ch8 应 ≈ 0.06 A |
| R、Lq 准确 | R ≈1 %/Ω；Lq 可忽略（0.14 V ≪ 6.05 V） | — |
| **Udc 准确** | **≈1:1（最大误差源，±3 % → ±3.1 %）** | 母线未进 ADC ⇒ 待做实验 |

**② 算 Δt：架构决定的常数（不需要实验）**

延迟不是"玄学"：它由编译好的时序决定，逐项加起来就是答案，和实测相位吻合（见 ③）。

```
已知  ：中频环周期 T_mid = 1/10 kHz = 100 µs；PWM 周期 T_pwm = 1/20 kHz = 50 µs
条件  ：编码器帧在中频环起帧、**下一拍**才被读走；CCR 在下一个更新事件生效
公式  ：Δt ≈ T_mid + T_pwm
计算  ：100 + 50 = **150 µs**
得到  ：Δt = 150 µs（○架构常数，不是拟合值）
```

| 环节 | 延迟 | 依据 |
|---|---|---|
| MT6701 锁存（CSN 下降沿）→ 数据有效 | 0 | 采样时刻就是 CSN 下降沿 |
| 24 bit 传输 @10.625 MHz | 2.26 µs | 24 / (170 MHz ÷ 16) |
| DMA 完成 + CRC 校验（中断内查表） | ~1 µs | 51 条指令 |
| **一整拍中频环**（帧在 t_{k−1} 采、t_k 才读走） | **100 µs** | = T_mid，**主导项** |
| 控制计算（Park/PI/SVPWM/写 CCR） | 3~5 µs | ISR ≈450~500 条 @170 MHz |
| CCR 生效（中心对齐更新事件） | 0~50，均值 25 µs | = T_pwm/2 |
| 中频更新 → 高频使用的相位差 | 0~50，均值 25 µs | = T_pwm/2 |
| **合计** | **≈150 µs** | |

未建模项（编码器内部处理、ISR 入口、DMA 中断）合计 ~3~4 µs（2.3 %）⇒ 该常数精度约 **±5 µs ≈ ±0.5° @2578 rpm**。写进固件就是 `ENC_ANGLE_LAG_US = 150`。

**改架构就要重算**（Δt 是架构量，不是电机参数）：

| 改动 | 新的 Δt |
|---|---|
| 中频环 10 kHz → **5 kHz**（`CONTROL_MID_DIV` 改 4） | 200 + 50 = **250 µs** |
| 中频环 → 20 kHz | 50 + 50 = 100 µs |
| PWM 20 kHz → 10 kHz | 100 + 100 = 200 µs |
| PWM → 40 kHz | 100 + 25 = 125 µs |

> 若要把**上电零位误差**与延迟一起辨识（本节的设定是"零位误差无所谓"），那是另一套做法：扫转速 + 回归，见**第 9 章**。

**③ 同时测量：同一帧把两者都对上**

**关键**：一次稳态测量给出的电压矢量有**两个"正交"观测量** —— 幅值只含 ψf，相位只含 δ：

```
u_d' = −ωe·Lq·i_q + ωe·ψf·sin δ          ← 相位携带 δ
u_q' = +R·i_q    + ωe·ψf·cos δ            ← 幅值携带 ψf
⇒ ωe·ψf = √((u_d' + ωe·Lq·i_q)² + (u_q' − R·i_q)²)      （就是 ① 的幅值法）
⇒ δ      = atan2(u_d' + ωe·Lq·i_q , u_q' − R·i_q)        （相位法，**不需要 ψf、不需要 Udc 准**）
```

所以 ① 与 ② 不是两次实验：**同一帧数据既算出 ψf（幅值），又给出 δ（相位）用来核对 ② 的架构常数**。

```
已知  ：点 B 的同一帧：Ud = −0.239、Uq = 0.980、iq ≈ 0.06 A、ωe = 1717.5 rad/s
条件  ：稳态、电压饱和
实测  ：u_d'·(Udc/2) = −1.434 V、u_q'·(Udc/2) = 5.880 V
公式  ：幅值 → ψf ；相位 → δ（上式）
计算  ：幅值：√((−1.434+0.144)² + (5.880−0.21)²) = 5.815 V ⇒ ψf = 0.00339 Wb ✓（与 ① 一致）
        相位：δ = atan2(−1.290, 5.670) = −12.8°
        架构：ωe·Δt = 1717.5 × 150e-6 = 14.76°
得到  ：幅度上两者一致（~13° 量级）、差 ~2° ⇒ 这 2° 是**本次上电的零位误差**，
        不属于本节内容（归 E2：齿槽导致每次上电 3~5° 随机），本节只需知道它存在
```

**两个观测量的误差结构互补**（这也是把它做成自动辨识的底气，见第 9 章）：

| 输入扰动 | ψf（幅值） | δ（相位） |
|---|---|---|
| Udc ±3 % | **±3.1 %**（最大误差源） | **±0.03°**（u_d、u_q 同比例缩放，近乎免疫） |
| R ±20 % | ~0 | ±0.09° |
| Lq ±20 % / iq ±30 % | ±1.2 % | ±0.28° |

**ψf 的第三方独立校验**

```
已知  ：Kv ≈ 400 rpm/V（规格书）、pp = 7
公式  ：ψf = 60/(2π·Kv·pp)
计算  ：60/(2π×400×7) = 0.00341 Wb
得到  ：三法一致（① 点 B 0.00340 / ① 点 A 0.00338 / Kv 法 0.00341）⇒ 取 ψf = 0.0034 Wb
        另一独立途径：断电外部拖动 + 万用表量线-线 RMS，ψf = 0.8165·V_LL_rms/ωe（i_d = i_q = 0）
```

**本节小结**

| 项 | 内容 |
|---|---|
| 本节产出 | ψf = 0.0034 Wb（≈反推）、Δt = 150 µs（○架构常数） |
| 一次实验同时得到 | 幅值 → ψf ；相位 → δ（核对 Δt）；\|\|u\|\|、n、i_d/i_q 顺带 |
| 假设（可验证） | 稳态；顶速点电流小（ch8 ≈ 摩擦、\|ch7\| ≤ 0.02 A）；\|u\| 同帧算出；i_d 已知 |
| 主要灵敏度 | ψf：**Udc ≈1:1**、i_d 0.41 %/0.01 A、R ≈1 %/Ω；δ：对上述几乎免疫 |
| 坑 | 把"顶速时 ch8 ≈ 0.06 A"当故障（正常，环路已饱和）；用 u_d 一条方程同时解 ψf 和 δ（2 未知数）；把相位与架构预算的差值当成延迟误差（那其实是零位误差，归 E2） |

## 2.7 E7 顶速调试史：1947 → 2578 rpm

**一句话**：顶速不足是**四个独立原因叠在一起**，逐个解决才逼到规格书的 99.2 %。

| # | 改动 | 位置 | 转速 | 为什么 |
|---|---|---|---|---|
| — | 基线 | — | 1947 rpm | — |
| ① | `CURRENT_U_MAX` 0.95 → **1.10** | `control.h` | 1947 → 2280 | 原取值过保守；SVPWM 线性区到 2/√3 = 1.1547 |
| ② | ADC 触发点移到**计数器波峰** `TIM1->CCR4 = ARR−1` | `drv8311_cur.c` | 与①配套 | 提高调制比后原触发点落在开关沿 ⇒ 相电流读数被污染 |
| ③ | 幅值近似 `max+0.5·min` → **`0.9604·max+0.3978·min`** | `mc_current.c` | 2280 → 2451 | 旧式斜方向**高估 11.8 %**：真值 1.008 被判成 1.10 ⇒ 白扔 9 % 电压 |
| ④ | 角度延迟前推补偿，`ENC_ANGLE_LAG_US = 150` | `control.h`+`Foc_GetSinCos` | 2451 → **2578** | δ≈14° ⇒ 转矩 ∝cos δ 且被迫多输出 Ud = −0.239 |
| ⑤ | （只改重复性）锁轴电压 0.15 → **0.30** | `control.h` | 让 2578 可重复 | 零位残余 6~9° → 3~5° |

```
已知  ：u_max 原值 0.95、线性区上限 2/√3、顶速基线 1947 rpm（✓）
条件  ：自由轴、iq* = 0.5 A、电压饱和；每次只改一项
实测  ：改动前后 ch2：1947 → 2280 → 2451 → 2578 rpm
公式  ：① n ∝ u ；② d_max = 0.5 + 0.25·|u|·√3 ；③ |u| ≈ 0.9604·max + 0.3978·min
        ④ θ_used = θ_meas + ωe·Δt
计算  ：① 0.95→1.10 即电压 +15.8 % ⇒ +17 % 转速；② u = 1.10 时 d_max = 0.976、采样窗口 1.18 µs
        ③ 释放被误锁的 9 % 电压；④ 消除 δ≈14° 的 cos 损失与 1.43 V d 轴白耗
得到  ：2578 rpm = 规格书 2600 的 99.2 %
```

**还差最后 22 rpm（2578 → 2600）**

```
已知  ：ψf = 0.0034 Wb、pp = 7、R = 3.5 Ω、Udc/2 = 6 V、i_q ≈ 0.06 A
条件  ：自由轴稳态
公式  ：u(n) = [ψf·pp·(2πn/60) + R·i_q] / (Udc/2)
计算  ：2578 → 1.106（与实测 u_max = 1.10 吻合 ✓）；2600 → **1.115**；2620 → 1.123
        勘误：早期写"2600 需要 1.19"不成立 —— 1.19 实际对应 2781 rpm
得到  ：2600 rpm 只需 u = 1.115，比现限幅高 1.4 %
```

**但天花板不是线性区，而是低边电流采样窗口**

```
已知  ：SVPWM（min-max 注入）；20 kHz ⇒ Ts = 50 µs
条件  ：最坏相位（矢量落在两相之间，三相占空比 max−min = √3）
公式  ：d_max = 0.5 + 0.25·|u|·√3 ；低边导通窗口 = (1 − d_max)·Ts
计算  ：1.100 → 0.976 → 1.18 µs（现用，采样点取波峰前 ~0.6 µs）
        1.115 → 0.979 → 0.9 µs（余量极小）；1.150 → 0.998 → 0.1 µs（不可用）
        1.1547 → 1.000 → 0（线性区边界，物理上到不了）
得到  ：u 的实际上限 ≈1.10~1.12（由采样窗口决定，与线性区 1.1547 无关）
```

想稳到 2600+ 的四条路：① **母线抬到 13.5~14 V**（不改代码，2685~2850 rpm）；② 消掉零位残余（旋转标定，拿回 ~20~30 rpm）；③ `CURRENT_U_MAX` 推到 1.12~1.13 并重排采样点（风险高）；④ 过调制/六步（>1.1547，需改代码 —— 规格书 2600 很可能是这么测的）。

## 2.8 E8 速度环（MODE_SPEED_CURRENT_LOOP）：测 J、定带宽

**一句话**：速度环是"转速 → 电流给定"的外环，只需要你给两个数：**转速目标**与**最大电流（用户限幅）**。

**两个指定量**

| 指定量 | 字段 | 上电默认宏 |

```
换算  ：kp[A/rpm] = 18.43·J·BW ；ki = 1.571·kp·BW
得到  ：见下面推荐表
```

**测试条件（最容易搞错的一条）**：`CAL: dir=… ok`；**轴自由**（夹死会退化成电流环测试）；**给定斜坡设 0（阶跃）或 20000 rpm/s**。

**看四条曲线**：ch2(rpm) / ch14(spd_ref) / ch15(iq_ref) / ch8(Iq)。期望：rpm 平滑跟随；加速段 `iq_ref = J·α/Kt + 摩擦`（**不是**顶在限幅）；稳态 `iq_ref ≈ 摩擦`、静差 ≈0。

| 故障现象 | 原因 | 对策 |
|---|---|---|
| **恒幅振荡**（如 896~1100 rpm） | 环路增益相对"实际 J + 反馈延迟"过高 ⇒ 极限环 | 降带宽（kp ∝ BW、ki ∝ BW²） |
| 高频嗡嗡（20~30 Hz） | kp 偏大 / 延迟偏大 | 降 kp，或按实测 J 重算 |
| 低频喘振（0.2~1 s） | ki 偏强 | `SPEED_KI_RATIO` 0.25 → 0.1；置 0 做纯 P 判别 |
| rpm 往反方向跑 | 不是速度环问题：角度方向 / Iq 符号 | 回 E5 夹死验证 |
| rpm 不动、iq_ref 贴限幅、电流在 **q** 轴 | 最大电流给太小（低于摩擦/齿槽） | 提高用户限幅 |
| rpm 不动、电流在 **d** 轴 | 角度/方向错 | 回 E2 |
| 一直 `FAULT: OC trip` | 限幅层级不对 / 电流符号反 | 查三层限幅与 `DRV8311_I_SIGN` |

**振荡周期怎么读**：50 Hz 采样看 20~30 Hz 会**混叠成拍频**（像慢摆）⇒ 把 `PRINT_PERIOD_MS` 改 10（100 Hz；CSV 一行约 110 字节 ≈9.5 ms，够用）。

**ch2 那 ±20 rpm 是环路振荡还是测量噪声底？（尚未判定）**

编码器 14 bit ⇒ 1 LSB = 0.022° 机械；转速按 100 µs（10 kHz）差分 ⇒ **原始量化台阶 = 36.6 rpm**，
经 95 Hz 反馈低通（α = 0.06）后本就落在 ±10 rpm 量级，再被 50 Hz 的 CSV 采样混叠 ⇒ ±20 rpm 更像噪声底。
三个判别法（从便宜到贵）：

1. **看 ch15 的 min/max**：ch2 在摆而 **ch15 基本是平线** ⇒ 测量噪声（10 Hz 带宽的环不该、也跟不上 95 Hz 以上的噪声）；
   ch2 与 ch15 **同步摆动** ⇒ 真振荡，环路在往回转矩；
2. **把 kp 改动 2~3 倍**（调试器里直接写 `mc.speed.pid.kp`，不用重烧）：摆幅明显变 ⇒ 环路；纹丝不动 ⇒ 噪声；
3. **改给定转速**：量化噪声换算到 rpm **与转速无关**（恒 36.6 rpm 的原始台阶）⇒ 500 / 2000 rpm 下仍是 ±20 rpm ⇒ 噪声；
   随转速成比例变大的才是机械纹波。

（齿槽可排除：1000 rpm 下齿槽基频 = LCM(12,14) × 16.67 rev/s ≈ **1400 Hz**，远在 95 Hz 反馈滤波与 10 Hz 环路带宽之外。）

**带宽上限的真正来源是反馈滤波**

```
已知  ：α = 0.06（SPEED_LPF_ALPHA）、dt = 1e-4（10 kHz）
公式  ：τ = dt/α ；fc = 1/(2πτ) ；相位滞后 = −atan(f/fc)
计算  ：τ = 1.667 ms → fc = 95.5 Hz ；滞后：95 Hz→45°、30 Hz→17.5°、20 Hz→11.9°
得到  ：速度环带宽取 20~40 Hz；目标 PM 55~60° 对应 BW 20~25 Hz
```


⚠ **但这个两点拟合没有证据力，不要据此改 `ENC_ANGLE_LAG_US`**：两测点来自**不同次上电**，而 δ0 每次上电随机 3~5°——
只要两次上电的零位残余差 2°，就会伪造出 **30 µs** 的假延迟误差，而拟合出的偏差只有 19 µs，完全埋在里面。
要真正拆开，必须**在同一次上电内**扫转速（做法见第 9 章 / 7. 待办 #6），可用调试器直接改 `mc.target.spd_target`（不用重烧）。

**若要把零位误差与延迟一起辨识**（本项目暂不需要）：扫转速 + 回归，`δ_res(ωe) = δ0 + ωe·Δerr` ⇒ 斜率给延迟修正、截距给零位残余。公式与工程细节见**第 9 章**。

## 3.8 速度反馈滤波（决定速度环带宽上限）○

```
已知  ：α = 0.06（SPEED_LPF_ALPHA）、dt = 1e-4（10 kHz）
公式  ：τ = dt/α ；fc = 1/(2πτ)
计算  ：τ = 1.667 ms → fc = 95.5 Hz
得到  ：速度环带宽上限 ≈20~40 Hz（95 Hz 处相位滞后已 45°）
```


# 第 5 章 自举与依赖

**为什么"用电流环测 R"不是循环依赖**

```
已知  ：PI 含积分
条件  ：给定为阶跃、输出未饱和、反馈符号正确
公式  ：I 型系统对阶跃输入稳态误差为 0 ⇒ i_fb = i_ref（精确）
        ⇒ 此时 u_q 恰为物理所需电压 ⇒ R = u_q·(Udc/2)/i_q
得到  ：R 的测量与 kp/ki 无关 —— 增益只影响动态，不影响直流工作点
```
**更彻底**：测 R 完全可以不用电流环 —— 开环给恒定电压矢量，等 >5τ 读电流（3.1 方法 2/3）。

**自举顺序（一轮收敛）**

```
① R/L 初值：万用表 R_LL/2 + 规格书电感（±20 % 够用）
② 用保守增益建电流环（BW 50~100 Hz）：一阶 RL 最小相位无谐振 ⇒ 必然稳定
   例：BW = 100 Hz → kp = 0.147、ki = 366
③ 环跑通后，用稳态两点法精测 R（顺带可测 L）
④ R/L 回代重算 kp/ki，带宽提到设计值（400 Hz），复测阶跃
⑤ 再用顶速数据测 ψf（幅值法，与 δ 无关）；Δt 直接用架构常数 T_mid + T_pwm
```

**为什么 R 可以粗、J 必须准**

```
R：只决定电流环 ki 的零点位置 → 差 20 % 只是零点在 2000~3000 rad/s 间挪动，PM 变化很小
J：直接决定速度环交越频率（∝1/J）→ 估大 7 倍使交越 30→119 Hz、PM 52.7°→11.8° ⇒ 必振
```

**反向标定：用万用表 R 标定电流采样链**

```
已知  ：万用表测得的 R_true（独立于固件）
实测  ：E5 稳态算出的 R_meas
公式  ：设 k_true = k_nom·(1+ε) ⇒ R_meas = R_true/(1+ε)
得到  ：ε = R_true/R_meas − 1 —— 用已知电阻反标采样链绝对增益
```

# 第 9 章 自动参数辨识（自整定）方案

> 前面几章是"人在台架上，看 CSV 扫参数"。**自动辨识**要把观测、判据、解算全部搬进固件：固件自己产生观测量、自己做稳态判据、自己最小二乘、自己报可信度。

## 9.1 三个层次的手段（按可靠性/成本递增）

| 层次 | 方法 | 需要什么 | 精度 | 说明 |
|---|---|---|---|---|
| **L1 架构预算** | `Δt ≈ T_mid + T_pwm` | 只读编译期常数 | ±3 %（±5 µs） | 零测量、零风险；**必须做**，用作先验与合理性上界 |
| **L2 在线相位观测** | `δ = atan2(u_d' + ωe·Lq·i_q, u_q' − R·i_q)` | R、Lq、i_q；**不需要 ψf、不需要 Udc 准** | 单点约 0.1~0.5° | 每拍都能算，是最核心的观测量 |
| **L3 扫转速 + 回归** | 拟合 `δ_res(ωe) = δ0 + ωe·Δerr` | L2 + 若干转速点 | 斜率项 ~1 µs | 把"零位误差"与"延迟"**解耦**的唯一办法 |

## 9.2 观测量与公式

```
控制器坐标系下（电流环把 i_d' 调成 0）：
  u_d' = −ωe·Lq·i_q + ωe·ψf·sin δ
  u_q' = +R·i_q    + ωe·ψf·cos δ
⇒ 幅值（求 ψf）：ωe·ψf = √((u_d' + ωe·Lq·i_q)² + (u_q' − R·i_q)²)
⇒ 相位（求 δ）  ：δ      = atan2(u_d' + ωe·Lq·i_q , u_q' − R·i_q)
（u_d'、u_q' 用伏特：u·(Udc/2)。幅值式在 i_q→0 时退化为纯 ωe·ψf）
```

灵敏度（本例 2343 rpm）：**δ 对 Udc ±3 % 只变 0.03°、对 R ±20 % 变 0.09°**；而 ψf 对 Udc 是 1:1。⇒ 相位观测量天然适合自动（少依赖标定不准的量）。

## 9.3 延迟与零位的解耦：扫转速 + 最小二乘

```
模型：δ_res(ωe) = δ0 + ωe·(Δt_true − Δt̂)
   δ0      零位误差（常数角；也可折进编码器 offset）
   Δt̂      固件里正在用的补偿值
做法：在 n 个转速点各测 δ 一次（每点先等稳态、再滑窗平均），最小二乘拟合 a + b·ωe
   ⇒ Δt_true = Δt̂ + b      （斜率给出延迟修正）
   ⇒ δ0      = a            （截距给出零位残余）
数值示例：Δt_true = 150 µs、δ0 = 3°
   Δt̂ = 150 µs  ⇒ δ_res 恒为 3°（斜率 0）⇒ 拟合得 Δt_true = 150 µs、δ0 = 3° ✓
   Δt̂ = 120 µs  ⇒ δ_res = 4.0°(800rpm) → 6.0°(2400rpm)，斜率对应 30 µs ⇒ 补回 150 µs ✓
```

> **关键限制**：在**单一恒定转速**下，δ0 与 Δt 产生的角度偏差完全等价、不可分辨。所以自动辨识**必须扫转速**；运行中的连续自适应只能修正"当前转速下的两者之和"（仍有价值）。

## 9.4 完整自辨识序列（状态机）

```
IDLE
 └→ R_ID      ：给 d 轴直流（转子被电磁"钉住"）→ 稳态 u_d/i_d → R；顺带测 L（电压阶跃拟合 τ）
 └→ PSI_ID    ：小 iq 升到中速（避开限幅）→ 幅值观测量 → ψf
 └→ DELAY_ID  ：在 3~5 个转速点（例 800/1200/1600/2000 rpm）：
                  每点等稳态 → 滑窗平均 u_d/u_q/i_d/i_q/ωe → 算 δ → 存点
                全部点做最小二乘 → Δt_true、δ0
 └→ APPLY     ：写 enc_lag_us = Δt_true；δ0 折进 enc_offset（或作为已知残差保留）
 └→ DONE / SUSPECT（拟合残差超阈值、或点数不足、或中途触发限幅/过流）
```

**每步的工况要求**

| 步骤 | 工况 | 判据 | 注意 |
|---|---|---|---|
| R_ID | 转子被直流钉住（不需要机械夹具） | u/i 稳定、\|u\| < 0.5·u_max | 电流不要大，避免温升影响 R |
| PSI_ID | 自由轴、中高速、轻载 | \|u\| ≤ 0.85·u_max（**避开限幅**） | 电流小 ⇒ 幅值式更准 |
| DELAY_ID | 自由轴、转速扫描 | 每点：转速波动 < 1 %、滑窗 ≥ 200 拍、\|\|u\|\| ≤ 0.85·u_max | 转速点覆盖越宽，斜率越准 |

## 9.5 工程细节（自动辨识成败就在这些）

1. **必须避开电压限幅**：饱和时 u_d' 受矢量限幅与抗饱和状态影响，观测被污染；用 `|u| ≤ 0.85·u_max` 对应的转速上限（本例约 2100 rpm）
2. **转速范围选择**：δ 的灵敏度 ∝ ωe（越高越准），但上限受限幅约束 ⇒ 800~2000 rpm 是合适区间
3. **稳态判据是必需的**：转速波动阈值 + 滑窗平均 + 方差阈值；否则回归点被瞬态污染，斜率全错
4. **可信度自检**（自动系统的"人眼"）：拟合残差 > 0.5°、或点数 < 3、或斜率对应 |Δerr| > 50 % × Δt̂ ⇒ 报 `SUSPECT`，沿用现有 `calib_report` 机制上报
5. **符号与极性**：`atan2` 直接给符号 ⇒ 补偿方向自动确定，无需人工试
6. **温度漂移**：R 随铜温 0.4 %/°C 变，但 R·i_q 项在 δ 里贡献很小（±20 % → 0.09°）⇒ 不影响
7. **负载影响**：i_q 变大时 Lq·i_q 修正项变大（用**实测 i_q** 而不是假设摩擦，即可自动适应）
8. **用实测母线电压**（若有 V_Bus 采样）：幅值式（ψf）立刻从 ±3 % 改善到 <1 %；相位式几乎不受益（本来免疫）
9. **可选增强**：把 δ0 折进 `enc_offset` 后，**每次上电**跑一遍 L2/L3 就能自动压掉齿槽造成的 3~5° 随机零位误差 —— 这正好是最影响顶速的那一项
10. **无位置传感器系统**：延迟问题转化为观测器的角度误差，需要另一套（反电动势相位法），不在本方案范围

# 附录 C：公式速查

```
# 换算
相电压峰值 = u·(Udc/2)        ωe = pp·ωm        rpm→rad/s：×2π/60
θe = dir·pp·θm + offset

# 电机模型
u_d = R·i_d − ωe·Lq·i_q
u_q = R·i_q + ωe·(Ld·i_d + ψf)
|u|² = (R·i_d − ωe·Lq·i_q)² + (R·i_q + ωe·Ld·i_d + ωe·ψf)²
T_e = Kt·i_q ，Kt = 1.5·pp·ψf
J·dωm/dt = T_e − T_fric − B·ωm

# 参数辨识
R  = u_q·(Udc/2)/i_q                        （夹死轴稳态）
R  = (u2−u1)·(Udc/2)/(i2−i1)                （两点斜率，消管压降）
L  = R·τ ，τ 由 i(t) 拟合
ψf = [√((|u|Udc/2)² − (R i_d − ωe Lq i_q)²) − R i_q − ωe Ld i_d]/ωe   （幅值法）
ψf = 60/(2π·Kv·pp) ；ψf = 0.8165·V_LL_rms/ωe                          （对照法）
J  = Kt·(i_q − i_q,fric)/α ；J = Kt·(I2−I1)/(α2−α1)                  （斜坡/两点）
Δt ：min|u_d|，理论下限 |u_d| = ωe·Lq·i_q/(Udc/2)
     先验估算：Δt ≈ T_mid + T_pwm（中频环周期 + PWM 周期）—— 本项目 100+50 = 150 µs
δ_res(ωe) = δ0 + ωe·(Δt_true − Δt̂)         （零位 + 延迟）
Δt_true = (ω1·Δt̂1 − ω2·Δt̂2)/(ω1 − ω2) ；δ0 = ω1·(Δt̂1 − Δt_true)      （两转速解耦）
齿槽周期（电角度）= 360/LCM(槽,极) × pp

# 增益设计
电流环：kp = L·ωc/(Udc/2) ，ki = R·ωc/(Udc/2) ，ωc = 2π·BW
速度环：kp = J·ωsc/Kt ，ki = kp·ωsc/4 ；kp[A/rpm] = 18.43·J·BW
限幅  ：I_stall = u_max·(Udc/2)/R
采样窗口：d_max = 0.5 + 0.25·|u|·√3 ，窗口 = (1−d_max)·Ts
顶速  ：n_max ≈ u_max·(Udc/2)/(ψf·pp)·(60/2π)

# 转速下的稳态电压（校验用；**不能**用堵转公式）
u_q(调制比) = [R·i_q + ωe·ψf]/(Udc/2)        u_d(调制比) = [R·i_d − ωe·Lq·i_q]/(Udc/2)
  堵转 ωe=0 才退化成 u_q = R·i_q/(Udc/2)（E5 测 R 用的就是它）
  1000 rpm 例：反电动势项 2.49 V 是电阻项 R·i_q = 0.12 V 的 20 倍 ⇒ 漏掉它会差一个数量级

# 相位/幅值两个正交观测量（自动辨识核心）
ωe·ψf = √((u_d' + ωe·Lq·i_q)² + (u_q' − R·i_q)²)        （幅值 → ψf，卡 Udc）
δ      = atan2(u_d' + ωe·Lq·i_q , u_q' − R·i_q)           （相位 → δ，几乎免疫 Udc/R/Lq）
δ_res(ωe) = δ0 + ωe·(Δt_true − Δt̂) ；拟合 a + b·ωe ⇒ Δt_true = Δt̂ + b、δ0 = a

# 相位裕度
L(s) = (kp + ki/s)·[Kt/(J·s)]·[1/(1+s/ωf)]·[1/(1+s/ωc)]·e^(−sT)
ωf = 2π·95（速度反馈低通），ωc = 2π·400（电流环），T ≈ 150 µs
PM = 180° + ∠L(jωx)，ωx 由 |L| = 1 决定
```

# 附录 D：三个待测量的实验步骤

共同瓶颈先说清：**这个电机太轻，动态过程只有几十毫秒，而 CSV 只有 50 Hz（20 ms/点）**。所以：
**只看"平均值"的量（摩擦、J）用现有工具就够；要看"波形"的量（带宽、阻尼）必须把打印提到 100 Hz，或加固件内高速采样。**

| 目标 | 现有工具 | 方法 | 需要改什么 |
|---|---|---|---|
| 摩擦电流 iq_fric | ✓ 够 | 速度环稳态取 ch15 平均 | 无 |
| J 精确值 | ✓ 够（斜坡差分） | 两档斜坡取中段平均，**摩擦自动抵消** | 只改 `SPEED_REF_RAMP_RPM_S`（两次烧写）；建议 `PRINT_PERIOD_MS=10` |
| 实际可用带宽 | △ 勉强 | 加大增益直到恒幅振荡，记振荡频率 f_u | `PRINT_PERIOD_MS=10`；更准需固件内高速采样 |

## D.1 摩擦电流 iq_fric

```
已知  ：Kt = 0.0357 N·m/A；速度环稳态时积分器自动把 iq_ref 顶到"抵消摩擦/负载"的值
条件  ：MODE_SPEED_CURRENT_LOOP，轴自由，目标转速固定，等稳态（rpm 波动 < 1 %）
实测  ：ch15（iq_ref）在稳态段的**平均值**（取 2~5 s ≈ 100~250 个点）
公式  ：iq_fric(n) = 稳态 iq_ref 的均值
计算  ：500 / 1000 / 1500 / 2000 rpm 各测一次 → 拟合 iq_fric = iq_c + b·n
得到  ：**1000 rpm 已测 = 0.033 A（✓实测，见 3.6）**；多转速点尚未做
        iq_c（库仑摩擦等效电流，预期 0.03~0.04 A）、b（粘滞+风阻，预期很小）
```

注意：① 要**平均值**不是瞬时值（ch15 被齿槽纹波调制）；② 平均窗尽量覆盖整数圈（1000 rpm 时 1 圈 = 60 ms = 3 个 50 Hz 点，取 50 点 ≈ 16 圈）；③ **副产品**：ch15 的峰峰值 = 齿槽/纹波等效电流，可用于评估齿槽转矩。

## D.2 J 的精确值（两档斜坡差分）

**为什么不用教科书的"恒流加速法"**：J = 3e-6 时 0.35 A 给出 35 800 rpm/s ⇒ 0~1000 rpm 只要 **28 ms**，50 Hz CSV 只有 1~2 个点，斜率量不出来。

**改用斜坡差分**（把"加速度"换成一个可控且慢得多的量，并让摩擦项相消）：

```
已知  ：Kt = 0.0357 N·m/A；斜坡 3000 rpm/s 时已实测 ch15 中段均值 iq₁ = 0.061837 A
条件  ：MODE_SPEED_CURRENT_LOOP，轴自由；两档斜坡各做一次：
        档 1：SPEED_REF_RAMP_RPM_S = 3000 ；档 2：= 20000
        每次取"斜坡中段"（200~800 rpm）ch15 的均值；建议 PRINT_PERIOD_MS = 10
公式  ：J = Kt·(iq₂ − iq₁)/(α₂ − α₁) ，α = 斜坡[rpm/s] × 2π/60
计算  ：α₁ = 314.2、α₂ = 2094.4 rad/s²
        预期 iq₂ = iq_fric + J·α₂/Kt ≈ 0.033（实测摩擦）+ 0.176 = 0.209 A
        Δiq = 0.209 − 0.0618 = 0.147 A（电流分辨 ~1 mA ⇒ 误差 ~1 %）
        J = 0.0357 × 0.147 / (2094.4 − 314.2) = **2.95e-6 kg·m²**
得到  ：J ≈ 3.0e-6 kg·m²（≈反推；**不需要知道摩擦**，两档摩擦项相消）
```

校验与注意：
1. **摩擦抵消自检**：再加一档 10000 rpm/s；三档两两组合给出的 J 若一致（±5 %），说明模型成立
2. **确认实际斜率**：ch2 斜率应 ≈ 设定斜坡。速度环对斜坡的跟踪误差是**常数**（模型：`e_ss = 4α/ωsc²`，
   当前 BW=10 Hz 时 ≈ **3 rpm**，与 J、Kt 无关），不影响斜率，但要确认 ramp 期间未顶限幅。
   ⚠ 早先这里写的"≈150 rpm 滞后"来源不明（模型对不上），且**必须拿 ch2 与"斜坡后的给定"比**——
   `ch14` 打的是**恒定目标**而不是斜坡给定，在斜坡段会显示上百 rpm 的假差值（这很可能就是那个 150 rpm）。
3. **限幅检查**：iq₂ ≈ 0.211 A < 用户限幅 0.5 A ✓（留 20 % 余量）
4. **误差排序**：Kt（±3 %，继承 ψf）＞ iq 测量（~1 %）＞ 斜坡设定（很准）
5. 想更准只有一个办法：固件内高速采样（D.4），用真实斜率替代设定值

## D.3 实际可用带宽（经验法：加大增益找恒幅振荡）

**先决条件（✅已完成）**：`MOTOR_INERTIA` 已改为实测值 3.0e-6，所以 `SPEED_BW_HZ` 现在**名副其实**（10 Hz ⇒ kp = 5.53e-4，实测已不振）。历史对照：改之前文件里是 2e-5，所谓"10 Hz"实际给的是 kp = 0.00369（在真 J 下相当于 57 Hz 交越、PM 45°）——标签与物理完全脱节。

```
已知  ：J = 3e-6、Kt = 0.0357；相位裕度模型见 2.8
条件  ：轴自由；给定斜坡设 0（阶跃）；阶跃幅度 ≤ 下表（避免顶限幅把环路非线性化）
实测  ：每档增益下施加小阶跃（或轻拨转轴给扰动），看 rpm 振荡是**衰减**还是**持续**
        → 刚好开始持续振荡的增益 = 极限增益 Ku；记录振荡频率 f_u
公式  ：可用带宽 ≈ f_u / 2.5（对应 PM ≈ 50°）；保守取 f_u / 3
计算  ：f_u = 20 Hz → 可用 8 Hz ；25 Hz → 10 Hz ；30 Hz → 12 Hz ；40 Hz → 16 Hz
得到  ：实际可用带宽；并可反过来校正模型里的等效延迟 T
```

| 目标带宽 | J=3e-6 对应 kp (A/rpm) | 不顶限幅的阶跃上限 | 上升时间 |
|---|---|---|---|
| 10 Hz | 0.00055 | 841 rpm | 35 ms |
| 15 Hz | 0.00083 | 561 rpm | 23 ms |
| 20 Hz | 0.00111 | 420 rpm | 18 ms |
| 25 Hz | 0.00138 | 336 rpm | 14 ms |
| 30 Hz | 0.00166 | 280 rpm | 12 ms |

操作：**按 SPEED_BW_HZ 逐档 10 → 20 → 30 → 40 → 50**（每档烧写一次），每档记三件事：① 阶跃超调 ② 振荡是否衰减 ③ 若持续，数出 f_u。
辅助判据（不必找到振荡）：小阶跃上升时间 t_r（10~90 %）→ 带宽 ≈ 0.35 / t_r。
采样要求：`PRINT_PERIOD_MS = 10`（100 Hz）。25 Hz 振荡 ⇒ 4 点/周期，能数峰。

**与模型对照的价值**：模型说 kp = 0.01106 时交越 119.5 Hz、PM 11.8°（必振）。若实测 f_u 明显低于 119 Hz，说明模型里的 T = 150 µs **偏小**（还有未建模滞后）⇒ 可用 f_u 反推 T_eff 修正模型。

## D.4 共同瓶颈的两条出路

| 出路 | 说明 | 成本 |
|---|---|---|
| **只看均值** | 摩擦用稳态平均、J 用斜坡差分 —— 都不需要看波形 | 零 |
| **固件内"示波器模式"** | ISR 里把 (rpm, iq_ref, iq) 存进 RAM 环形缓冲（1~5 kHz × 256~512 点），测完由主循环 dump 成 CSV；阶跃/振荡能看全，J 与带宽都能测准一个数量级 | 约 80 行代码 + 8 KB RAM（G431 有 32 KB） |
